Savings Microservice

A banking demo composed of 8 cooperating microservices, fronted by an API gateway that demonstrates API composition.

Tech stack

  • Java 25, Spring Boot 3.5.x
  • Gradle 9 for builds
  • PostgreSQL 16 — one shared instance, one database per service
  • Hibernate via spring-boot-starter-data-jpa
  • Docker / Docker Compose for everything

API composition (the demo highlight)

In microservices, data is split across services. The front-end can't get a customer's full picture from one call. The api-gateway service solves this — it exposes a single composite endpoint that internally calls multiple downstream services and merges the result.

Demo endpoint to aim for:

GET http://localhost:8080/api/v1/composite/customer-overview/{customerId}

That call fans out to customer-service, account-service, and transaction-service, then returns one merged JSON.

Quick start

git clone <repo-url>
cd saving-product-service
docker compose up --build

Brings up Postgres + all 8 services + the gateway. First build takes a few minutes.
